## Supervised Learning
The "training data" consists of examples of a functional relationship
- most commonly-used learning process
- "fastest" way to learn - requires the least data

Quantitative label  -> regression
Categorical label -> classification

### Classification Problems
Binary classification: 0/1

How do we evaluate how good a classifier is?

- **accuracy** = $\dfrac{\text{num correct}}{\text{num total}}$

### Train-test Split

2 parts:
1. Larger Training Part (~80%)
2. Smaller Test Part (~20%)

| Only use Test set **once** after developing and training the model to avoid overfitting

### Exam analogy

Train: Practice exam with answer key
Validation: practice exam
Test: Actual exam
