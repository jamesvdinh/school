## Main Pillars
- **Incremental Work**
	- Customer satisfaction: deliver valuable software *early* and *continuously*
	- Frequent delivery: deliver working software in *short*, regular intervals
	- Sustainable pace: maintain a *consistent* and *manageable* development speed
	- Continuous improvement: regularly *reflect* and *improve processes* for better results
- **Teamwork & Communication**
	- Collaboration: ensure *daily* cooperation between business teams and developers
	- Motivated teams: build projects around skilled, trusted, and *motivated* individuals
	- Face-to-face communication: prefer *direct* communication
	- Self-organizing teams: encourage teams to take *ownership* and make decisions
- **Software Quality**
	- Working software: measure progress based on *functional software*, not just documentation
	- Technical excellence: focus on *good design* and *high-quality* coding practices
	- Simplicity: minimize unnecessary work and keep solutions *simple*

## SLDC
![[Pasted image 20260729131229.png]]
1. **Requirement Gathering**
	- the team identifies and documents the needs and expectations of various stakeholders
	- define project scope, objectives, and reqs
	- establish budget and schedule, project plan, and allocate resources
2. **Design**
	- develop a high-level system architecture
	- create detailed specifications -- data structures, algorithms
	- plan UI
3. **Development**
	- write actual code
	- conduct unit testing to verify functionality
4. **Testing**
	- Integration Testing: ensure different components work together
	- System testing: Testing the entire system as a whole
	- User Acceptance Testing: confirm that the software meets user requirements
	- Performance Testing: assessing system speed, scalability, and stability
5. **Deployment**
	- deploying software to prod
	- put software in real world for real users
	- make sure it works smoothly
	- provide training and support for end-users
6. **Review (Maintenance)**
	- address and resolving any issues that arise after development
	- release updates and patches to enhance the software
